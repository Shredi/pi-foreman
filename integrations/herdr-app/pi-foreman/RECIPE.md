# pi-foreman

An Agents list for the sidebar, grouped by space, that shows the pi-foreman session behind each agent: tier, cost, ask or waits, pull requests with their check state, nested sessions and workers. It replaces the shipped `agents` block of a cloned layout.

**What you see:** the shipped Agents list look (title "Agents" at 11.5px dim, space headers at 11px dim, agent rows 30px with program icon, name, machine, time in state and status glyph, footer "N agents · k need you"). Under an agent that is a foreman session: a 20px line with label, tier (dim), summed cost and "N sessions"; a 20px ask or waits line (red while blocked); a wrapping line of PR chips (18px pills, raised background, border red when a check fails, `⎇ #n` and one 7px dot per check) followed by a dim "N PRs · k failing · m pending" or "all green". Nested sessions are 26px tree rows (guides, label, own cost, up to two chips, status); more than two PRs go on a wrapping line under the row. Workers are 24px tree rows "role model" with a spinner. A final "Open PRs" section lists PRs nobody works on, one chip row per repo, and is hidden when empty.

**How it behaves:** working shows the spinner, blocked a red "Needs you" tag, done a filled dot, running child agents (radar runs or `pi-subagents` records from `hc get`) a hollow spinner with "N agents: titles", a background task a small square ("bg: name age"), a wait a hollow muted ring ("wait: note age"), idle a ring; ended sessions are hidden. Each running agent that radar does not already show as a row (radar runs keep their worker row) also gets a short indented line under its session or agent row (small spinner, red when blocked; `title · msg`; at most 4, then `+N more`). Clicking an agent runs `pane.focus`; a live hc child runs `terminal.peek`; a chip with an https URL opens it with the platform opener. Radar is polled every 3 s (15 s per remote space); on failure a dim "No foreman radar on <machine> (set props.foreman)" line shows and the poll retries every 30 s.

**Built from:** `herdr` `agents`, `terminals`, `focused`, `spaces`, `setAgentOrder`, `run`, `theme`, `exec`, `props`, `window`; `cx.timer.every`, `cx.spawn`. `model.js` is pure (parse, tree, join, rows, URL rule, opener argv) and has node tests. The only programs run: `foreman radar --json` (prop `foreman`, a path or an object keyed by machine with `local`) and the opener.

**Watch out:** join agents to radar nodes on `hcTerminal` (the `machine/` prefix for remote spaces), skip done nodes, require equal pids when both sides have one. Open only `https://` URLs without whitespace or `& | ^ < > " '`; call `hc` only as `hc get <terminal> --json` (argv, failures ignored), never write, never fetch. Never throw in render.

**Done when:** `herdr-app check` passes; with a radar that has a session in an agent terminal its rows appear under the agent; with no `foreman` the dim line appears; a bad URL never reaches the opener.
